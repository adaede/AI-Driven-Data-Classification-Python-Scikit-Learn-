# AI‑Driven Data Classification (Python, Scikit‑Learn)

This project demonstrates a complete machine learning workflow for classifying structured data using Python and Scikit‑Learn. It includes data cleaning, preprocessing, model training, evaluation, and saving the trained model.

## Features
- Data cleaning and preprocessing
- Train/test split
- Feature engineering
- Model training (RandomForest, Logistic Regression, etc.)
- Accuracy, precision, recall, F1-score
- Exporting trained model

## Tech Stack
Python • Pandas • NumPy • Scikit‑Learn • Matplotlib

## Project Structure
See repository folders for data, notebooks, source code, and saved models.

## How to Run
- pip install -r requirements.txt
- python src/train_model.py
- python src/evaluate.py


## Results
Model achieved strong performance with clear feature importance insights.
